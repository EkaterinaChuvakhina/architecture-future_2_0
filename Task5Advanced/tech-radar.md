# Будущее 2.0 Tech Radar 2026

**Горизонт планирования:** 3 года  
**Цель:** Переход к слабосвязанной событийной платформе на базе Data Mesh с self-service аналитикой

---

## 1. Architectural Patterns

| Компонент                                         | Статус    | Обоснование                                                                   |
|---------------------------------------------------|-----------|-------------------------------------------------------------------------------|
| Data Mesh                                         | **ADOPT** | Позволяет масштабировать разработку данных по независимым бизнес-доменам      |
| Event-Driven Architecture                         | **ADOPT** | Обеспечивает слабую связанность сервисов и переход к near-real-time обработке |
| Self-Service Data Platform                        | **ADOPT** | Прямо поддерживает требование бизнеса к самостоятельному построению отчётов   |
| Lakehouse Architecture                            | **TRIAL** | Объединяет возможности Data Lake и Data Warehouse, упрощая миграцию из DWH    |
| Saga Pattern                                      | **TRIAL** | Гарантирует согласованность данных в распределённых бизнес-процессах          |
| Outbox Pattern + Idempotency                      | **TRIAL** | Обеспечивает надёжную доставку событий и защиту от дублирования               |
| Anti-Corruption Layer                             | **TRIAL** | Позволяет безопасно интегрировать legacy-системы на этапе миграции            |
| DLQ + Retry Mechanisms                            | **TRIAL** | Повышает устойчивость обработки событий и снижает потери данных               |
| Monolithic DWH с бизнес-логикой (SQL Server 2008) | **HOLD**  | Создаёт bottleneck в разработке и сильно усложняет масштабирование            |
| Enterprise Service Bus (ESB)                      | **HOLD**  | Подход с синхронными интеграциями противоречит целевой архитектуре            |

- **ADOPT** — Рекомендуется использовать в новых проектах

- **ASSESS** — Требует дополнительного изучения и PoC
